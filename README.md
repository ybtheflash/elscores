# ENGLISH LEARNERS ISC/ICSE 2025 Results

This is a minimal Next.js 14 app for ENGLISH LEARNERS (myenglishlearners.in) to publish ISC and ICSE 2025 student results. It uses Tailwind CSS v4 and pnpm. The main page displays sortable/filterable tables for both ISC and ICSE, allows toggling between them, highlights the top 10 students, and supports color scheme switching.

## Features

- Toggle between ISC and ICSE results
- Sort and filter by Name, English Score, and Overall %
- Top 10 students highlighted
- Color scheme changes with board
- Data import from spreadsheet (coming soon)

## Getting Started

Install dependencies:

```sh
pnpm install
```

Run the development server:

```sh
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

---

This project is intentionally kept as light as possible for easy deployment and maintenance.
